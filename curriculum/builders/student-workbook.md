# Builders Student Workbook
**Document ID:** CSA-BLD-SW-EN-v1.0 · **Program:** Builders (Grades 2–3) · Print spec: 12 pt body, wide-ruled writing lines, code lines in large monospace boxes. Perfect-bound, perforated certificate.

*Designer note: Builders write real code by hand in this book before typing it. Code boxes use faint letter guides in Semester 1, fading out by Semester 3.*

## Semester 1 — All About Me Page 🏗️
**Opener:** Big Idea banner to colour: *HTML tags give structure and meaning to a page.*

| Page | Session | Activities |
|------|---------|------------|
| S1.1 | What Is a Website? | Label the page parts (heading / paragraph / picture) on a printed page. Handwrite your first tag in the guide box: `<h1>My name is ___</h1>` |
| S1.2 | Tag Team | Draw the "tag hug": match open tags to close tags with lines. Write your two section headings in `<h2>` boxes. Fix-it corner: circle what's wrong with `<p>Hello<p>` |
| S1.3 | Pictures & Order | Write alt text for 3 printed pictures ("what would you tell a friend who can't see it?"). Quiz-day "I can" check: *I can match open and close tags.* |
| S1.4 | The Page Skeleton | Boxes-in-boxes diagram to label: html / head / body / title. **Wireframe page:** draw your All About Me layout in labelled boxes. |
| S1.5 | Publish day ★ | My page tour card: "My page has ___ / My favourite tag is ___ / I'm proud of ___." Safe-sharing checklist to tick. Reflection: colour the confidence meter. |

## Semester 2 — Weather Helper ⛅
**Opener:** *CSS styling shapes how information looks and feels.* Colour the same page shown plain and styled.

| Page | Session | Activities |
|------|---------|------------|
| S2.1 | Same Page, New Clothes | Anatomy of a rule to label: `h1 { color: teal; }` (selector / property / value / don't-forget-the-semicolon). My favourite rule, handwritten. |
| S2.2 | Lists of Everything | Sort: which need `<ol>` (numbers) vs `<ul>` (bullets)? Write your "snowy day" list items. |
| S2.3 | Class Acts | Design your section moods: colour swatch + class name for each season (`.snowy`, `.sunny`…). "I can" check: *I can write a CSS rule.* |
| S2.4 | Building the Helper | Build checklist with tick boxes (sections / lists / classes / styled). Bug log: one thing that broke + how I fixed it. |
| S2.5 | Demo day ★ | Demo card: "My Helper covers ___ / I styled it to feel ___ because ___." Semester reflection (best / trickiest / next). |

## Semester 3 — Class Pet Care Guide 🐹
**Opener:** *Good writing makes information easy to use.*

| Page | Session | Activities |
|------|---------|------------|
| S3.1 | Who Is Our Pet? | Fact organizer: Eats / Plays / Needs / Watch out (writing lines). |
| S3.2 | Follow the Link | Trace the link journey: draw arrows between page boxes; handwrite one `<a href="...">` in the guide box. |
| S3.3 | Write So They Can Do It | Draft your feeding steps (numbered lines, verb-first reminders in margin). Revise-one-step box after partner reading. |
| S3.4 | Building the Guide | Site map to complete: Home / Feeding / Play & Care with link arrows both ways. Link test checklist. |
| S3.5 | Handover day ★ | Handover card: "If you looked after our pet, my guide shows you ___." Guest question + my answer box. Reflection meter. |

## Semester 4 — Save the Bees 🐝
**Opener:** *Websites can persuade people to care about something.*

| Page | Session | Activities |
|------|---------|------------|
| S4.1 | Why Bees? | Fact collector: 3 bee facts with a "source" line. Fact vs. opinion sort. Two headline drafts + star the stronger. |
| S4.2 | Design That Cares | Mood board: circle colours that feel like bees/nature; big-small-bold layout sketch. |
| S4.3 | Calls to Action | Write your call to action. "What You Can Do" list draft (3 doable things). Footprint check boxes: true ☐ kind ☐ safe ☐. |
| S4.4 | Building the Campaign | Build checklist; bug log round 2. |
| S4.5 | Launch day ★ | My 30-second campaign speech (writing frame). Audience response: "one thing I'll actually do" from a classmate. Semester reflection. |
