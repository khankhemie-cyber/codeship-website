# Builders Master Curriculum Manual
**Document ID:** CSA-BLD-MCM-EN-v1.0 · **Program:** Builders (Grades 2–3) · **Coding space:** HTML & CSS · **Journey arc:** Dream · **Accent colour:** #138A9A

## 1. Course overview

Builders move from blocks to real code, learning HTML structure and CSS styling while developing informational and persuasive writing skills for the web.

**Headline outcome (public promise):** *Builds and styles a real multi-page website.*

**Structure:** 4 semesters × 5 sessions + 2 capstone sessions = 22 × 55-minute sessions. 8 quizzes (2 per semester). One project per semester plus the capstone Community Helper Website. Session flow: Warm-up (5) → Teach (10) → Build (30) → Reflect (10) (→ CSA-STD-CF §4).

**Program skills (public promise):** Tags · Structure · CSS styling · Lists · Links · Informational & persuasive writing · Digital footprint.

**Tool:** browser-based HTML/CSS editor with live split preview (→ CSA-STD-CF §10). Builders type real code from session one, with typing demands scaled to Grades 2–3 (short snippets, generous starter files).

**Alignment posture:** designed to support Ontario's coding expectations; aligns with BC's ADST curriculum and Alberta's Computer Science outcomes for the primary grades. *Not endorsed or approved by any ministry of education.*

## 4. Weekly progression — full session sequence

### Semester 1 — All About Me Page
*Big Idea: HTML tags give structure and meaning to a page.*

| Code | Title | Objectives (students will…) | New vocabulary |
|------|-------|-----------------------------|----------------|
| S1.1 | What Is a Website? | identify parts of a real web page (heading, paragraph, picture); type their first `<h1>` and see it render | website, browser, HTML, tag |
| S1.2 | Tag Team | use `<h1>`, `<h2>`, `<p>` correctly; explain open/close tag pairs | heading, paragraph, open/close tag |
| S1.3 | Pictures & Order **(Q1)** | add an image with `<img>`; order page content sensibly | image, source, alt text |
| S1.4 | The Page Skeleton | describe head vs. body; nest tags correctly; plan their page's sections | head, body, nesting |
| S1.5 | All About Me — publish day **(Q2)** | complete and present a structured personal page (safe-sharing rules applied) | (review week) |

**Project milestone:** All About Me Page presented S1.5. **Success criteria:** h1 + 2 sections with h2/p; one image with alt text; content follows safe-sharing rules (first name only).

### Semester 2 — Weather Helper
*Big Idea: CSS styling shapes how information looks and feels.*

| Code | Title | Objectives | New vocabulary |
|------|-------|------------|----------------|
| S2.1 | Same Page, New Clothes | connect a style sheet; change colours and fonts; explain HTML=structure, CSS=style | CSS, style, property, value |
| S2.2 | Lists of Everything | build `<ul>` and `<ol>` lists; choose which fits (order matters or not) | list, bullet, numbered |
| S2.3 | Class Acts **(Q3)** | use classes to style chosen elements differently | class, selector |
| S2.4 | Building the Helper | assemble the Weather Helper: seasonal sections + dress-right checklists, styled to match each season | (applying) |
| S2.5 | Weather Helper — demo day **(Q4)** | finish, style-polish, and present | (review week) |

**Project milestone:** Weather Helper presented S2.5. **Success criteria:** 2+ weather/season sections; one correct list per section; CSS changes colour and font; a class used for at least one distinct style.

### Semester 3 — Class Pet Care Guide
*Big Idea: Good writing makes information easy to use.*

| Code | Title | Objectives | New vocabulary |
|------|-------|------------|----------------|
| S3.1 | Who Is Our Pet? | choose the (real or imagined) class pet; gather facts with the fact organizer; plan guide sections | fact, guide, audience |
| S3.2 | Follow the Link | create `<a>` links between two pages; explain how links connect the web | link, href, multi-page |
| S3.3 | Write So They Can Do It **(Q5)** | write clear numbered steps (feeding instructions) using informational-writing rules | steps, instructions |
| S3.4 | Building the Guide | assemble the multi-page guide (Home / Feeding / Play & Care) with navigation links | navigation |
| S3.5 | Guide handover day **(Q6)** | test all links; present the guide "so a pet-sitter could really use it" | (review week) |

**Project milestone:** multi-page Care Guide presented S3.5. **Success criteria:** 2–3 linked pages; numbered care steps a stranger could follow; working navigation both ways.

### Semester 4 — Save the Bees Awareness Site
*Big Idea: Websites can persuade people to care about something.*

| Code | Title | Objectives | New vocabulary |
|------|-------|------------|----------------|
| S4.1 | Why Bees? | gather bee facts; distinguish fact vs. opinion; draft a persuasive headline | persuade, fact vs. opinion, headline |
| S4.2 | Design That Cares | apply mood-matched styling (colour, size, emphasis) to strengthen the message | emphasis, design mood |
| S4.3 | Calls to Action **(Q7)** | write a call to action; add a "What You Can Do" list; check the site's digital footprint (what are we telling the world?) | call to action |
| S4.4 | Building the Campaign | assemble and polish the awareness site (headline, facts, action list, image) | (applying) |
| S4.5 | Campaign launch day **(Q8)** | present persuasively: "did it make you care?" peer response | (review week) |

**Project milestone:** awareness site presented S4.5. **Success criteria:** persuasive headline + 3 facts + call-to-action list; styling deliberately supports the message; child can name one fact and one opinion on their page.

### Capstone — Community Helper Website

| Code | Title | Objectives |
|------|-------|------------|
| C.1 | My Helper, My Site | choose a real community helper (crossing guard, librarian, firefighter, coach…); plan a multi-page site with the site map planner; build page one |
| C.2 | Launch & Celebrate | complete pages and navigation, style consistently, present at the family showcase |

**Success criteria:** 2+ linked pages about a real helper; correct tags and structure; CSS styling with intent; writing that informs (who they are, what they do) and persuades (why they matter); safe-sharing rules applied.

## 5. Timing, materials, and classroom preparation

- **Timing:** standard four-phase flow; quiz sessions (x.3, x.5) open with the 10-minute quiz (→ CSA-BLD-AM-EN).
- **Materials (whole program):** keyboard devices (one per student) with the class web editor and starter files loaded; instructor demo + display; printed tag reference cards; paper wireframe planners; workbooks; Printable Resource Book masters (→ CSA-BLD-PRB-EN).
- **Starter files:** every semester ships a starter project (pre-built skeleton with TODO comments) so typing load stays age-appropriate; students always type the *learning-target* code themselves.
- **Preparation:** room per CSA-STD-OPS §2; editor tested on every device; that session's printable copied; unplugged fallback packed (PRB-16).

## 6. Teacher notes (program level)

> **📌 Teacher Note:** Grades 2–3 typing is slow — that's fine. Success is *understanding the tags*, not words-per-minute. Starter files carry the boilerplate; children type the tags they're learning.

> **⚠️ Watch For:** the three classic beginner breakages — missing closing tag, missing quote mark, missing `>`. Teach the "tag doctor" checklist (PRB-10) early and celebrate every self-fix.

> **🤝 Every Learner:** lighter-load variants use fill-in-the-tag files; stretches add extra sections or styles. Handwriting-averse writers may dictate text content, then type the *tags* themselves — the coding objective stays intact.
