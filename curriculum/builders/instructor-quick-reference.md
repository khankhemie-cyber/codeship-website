## Timing guide

Warm-up 5 → Teach 10 → Build 30 → Reflect 10. Quiz days: Quiz 10 → Re-teach 5 → Build 30 → Reflect 10. Protect the Build.

## Troubleshooting (top 6)

| Symptom | Fix |
|---------|-----|
| Raw code showing | Missing `>` — tag doctor step 1 |
| Page all huge/bold | Unclosed tag — find the lonely opener |
| Image missing | src typo — copy-paste filename |
| Link dead | href ≠ filename (exact, with .html) |
| CSS ignored | Missing `;` or `{}`, selector typo — read rule aloud |
| Slow typist despairing | Success = understanding tags, not speed; lighter starter |

## FAQs

**Do Builders need to type well?** No — starters carry boilerplate; they type the learning-target code. **Is the writing part "extra"?** No — informational/persuasive writing is assessed curriculum (S3–S4). **Real pet required?** No — class may vote an invented pet with consistent facts. **Parent wants the site public?** Class environment only; safe-sharing gate is non-negotiable. **Child knows HTML already?** Stretch variants every session; placement questions → location lead.

## Closure script

"Builders, save your page… hands off keyboards, eyes here. HTML is the structure, CSS is the style. Goal's on the board — Dream. Code. Achieve!"
