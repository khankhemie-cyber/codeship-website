# Builders Printable Resource Book
**Document ID:** CSA-BLD-PRB-EN-v1.0 · **Program:** Builders (Grades 2–3) · Single-sided photocopy masters, black-and-white safe (→ CSA-STD-PUB §11).

---

## PRB-1 — Page Parts Scavenger Sheet (S1.1)
A printed kid-safe web page with a legend: circle the heading in red, paragraphs in blue, picture in green. Doubles as the diagnostic (AM §3).

## PRB-2 — Tag Cards (S1.2)
Cut-apart deck of open/close tag pairs in large monospace: `<h1>/<​/h1>`, `<h2>`, `<p>`, `<img>` (lone-wolf card, no partner — teaching point), `<ul>/<ol>/<li>`, `<a>` added from S2–S3. Match games, warm-ups, "find your partner" movement game.

## PRB-3 — Page Skeleton Poster (S1.4)
Boxes-in-boxes wall poster: `html` wrapping `head` (with `title`) and `body`. Blank version for students to label included.

## PRB-4 — Wireframe Planner (S1.4, S2.4, reused)
Full-page browser-window frame with dotted grid; students sketch layout boxes and label each with its tag. 2-per-page mini version for quick planning.

## PRB-5 — Safe-Sharing Checklist Card (S1.5, S4.3, C.2)
Card-stock personal checklist: first name only ☐ · no address/school/phone ☐ · class-folder images only ☐ · kind words only ☐ · true things only ☐ (last two highlighted for S4+). The web-era successor of the Explorers footprint.

## PRB-6 — Home Link Notes (Sx.5)
Half-page per semester, standard layout (What we built · Ask your Builder · Try at home): S1 label page parts in a magazine; S2 find lists in the kitchen; S3 write verb-first instructions for making toast; S4 spot a persuasive poster and name its call to action.

## PRB-7 — CSS Property Cards (S2.1)
Reference cards: `color`, `background-color`, `font-family` (4 kid-safe fonts), `font-size` — each with syntax example and "what it changes" picture. Anatomy-of-a-rule chant card included.

## PRB-8 — List Sort Cards (S2.2)
Sixteen scenario cards ("steps to brush teeth", "favourite fruits", "fire-drill steps", "party guests") to sort into ORDER-MATTERS (`<ol>`) vs ANY-ORDER (`<ul>`) hoops.

## PRB-9 — Fact Organizer & Writing Frame (S3.1, S3.3)
Front: Eats / Plays / Needs / Watch-out quadrant with source line. Back: numbered instruction frame with verb-first margin reminders and one-action-per-step rule strip.

## PRB-10 — Tag Doctor & Link Checklists (throughout)
Card stock, front/back. **Tag doctor:** 1 every `<` has a `>` ☐ · 2 every open tag has its close ☐ · 3 quotes come in pairs ☐ · 4 read it aloud slowly ☐. **Link check:** click every link ☐ · every page gets home ☐ · href matches filename exactly ☐.

## PRB-11 — Bee Fact Sheets (S4.1)
Two pages of age-levelled, verified bee facts with picture support (pollination plate: "1 in 3 bites"), each fact numbered for the source line. Fact/opinion sort cards on a third page.

## PRB-12 — Capstone Site Map Planner (C.1)
Spread: helper name & why · Page 1 (inform) box · Page 2 (persuade) box · link arrows · image plan · requirement checklist mirroring the capstone rubric.

## PRB-13 — Presentation Frame Cards (all x.5, C.2)
Palm cards per semester frame + the capstone frame ("My site celebrates… / Watch when I click… / I'm proud of…").

## PRB-14 — Visual Schedule & Agreements Posters
Shared design with all programs (→ CSA-STD-OPS §2, §5), Builders-teal accent edition.

## PRB-15 — Classroom Skyline Tracker
Wall version of the workbook skyline: one building per session; class colours it in together. First names only on rooftops.

## PRB-16 — Unplugged Fallback Pack
S1: paper-tag human page (kids hold tag cards and arrange themselves into a page) · S2: crayon CSS — style a printed plain page by hand from written "rules" · S3: string-and-card link web across the room · S4: paper campaign poster with headline/fact/CTA slots.

## PRB-17 — Certificate Master
Builder's Certificate line-art + navy/gold print version (criteria → AM §9).
