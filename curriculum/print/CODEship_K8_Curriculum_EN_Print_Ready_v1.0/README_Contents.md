# CODEship Academy — Complete K–8 Curriculum (English) · Print-Ready Edition v1.0

Everything in one package. Four programs, each a full teaching kit, verified and prepared for print submission. **English only; French kits and provincial crosswalk documents are intentionally excluded (per request).**

Start with **`00_PRINT_SUBMISSION_SPEC.pdf`** (the sheet for your print vendor) and verify received files against **`MANIFEST.csv`** (titles, page counts, SHA-256 checksums).

## What every program contains (16 files each)

- **1 × Curriculum Guide (Teacher Edition)** — scope & sequence, inclusive-design playbook, per-semester theory + lesson plans + project outline + rubric, and level assessment/graduation with the locked alignment-language rule.
- **5 × Student Workbooks** — one per semester (S1–S4) plus the Capstone. Each is 7 pages: cover, theory, 4 class worksheets, and the project planner.
- **5 × Quiz Packs** — one per block. Each is 4 pages: Quiz 1, Quiz 2 (10 questions each), and a teacher answer key. *Keys are the final page — keep packs out of student distribution.*
- **5 × Assessment Sheets** — one per block. Landscape rubric-recording + quiz/observation sheet with roomy "Notes / next steps."

**Totals:** 4 guides + 20 workbooks + 20 quiz packs + 20 assessment sheets = **64 documents** (+ this README, the manifest, and the print spec).
Structure per program: **4 semesters + 1 capstone**; each block = 4 classes → 1 project, 2 quizzes, and a theory component. Per level: 20 sessions · 5 projects · 8 semester quizzes · capstone gate.
