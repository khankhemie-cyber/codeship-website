## Timing guide (every session)

Warm-up 5 → Teach 10 → Build 30 → Reflect 10. **Quiz days:** Quiz 10 → Re-teach 5 → Build 30 → Reflect 10. Never let Teach eat Build.

## Setup checklist (before every class)

☐ Room/tech per OPS §2 (ready 30 min early; 8:30 for Saturday block)
☐ Block-coding app open to fresh project on every device
☐ Today's printable copied; workbooks + crayons out
☐ Visual schedule (PRB-13) + agreements (PRB-14) posted
☐ Unplugged fallback (PRB-16) in the bag
☐ Quiz day? Quizzes counted; stickers ready
☐ Roster + accommodation notes read

## Materials checklist (program cupboard)

Device set + spares (1 per 8) · instructor demo + display · arrow cards · trigger cards · tape floor grid · sorting objects (S3) · paper/crayons (S4) · badge stickers · card stock checklists · certificates.

## Software checklist

Visual block-coding app (ScratchJr-style) on all devices · class accounts only · mic permission enabled before S2.3 · settings locked from students.

## Assessment schedule

Diagnostic S1.1 · quizzes sessions x.3 and x.5 (Q1–Q8) · project rubric every x.5 · capstone rubric + certificates C.2 · record scores within 24 h · parent feedback (rubric + 2–3 sentences) after every x.5.

## Project schedule

Robot ★ S1.5 · Cards ★ S2.5 (recipient check S2.4!) · Sorter ★ S3.5 · Map ★ S4.5 · Capstone C.1–C.2 (family invite out 2 weeks before C.2).

## Missed-session compression

One session lost in a semester: merge x.1 into x.2's warm-up (plans shrink to 10 min), keep quiz days intact. Never cut the project day (x.5). Two+ lost: call curriculum lead (→ FDS §3).

## Troubleshooting (top 5)

| Symptom | Fix |
|---------|-----|
| Program does nothing | Missing start trigger / unsnapped blocks |
| Wrong direction | Floor-grid re-walk; arrow stickers on device |
| "I can't do it" | Lighter-load variant; you point, I drag; hand control back fast |
| Recording fails | Mic permission (instructor-only fix) |
| Frozen device | Swap for spare, restart later quietly |

## FAQs

**Do Explorers need to read?** No — everything is icon-first and read aloud. **Homework?** None; Home Links are optional family fun. **Can a child skip to Builders?** Placement is by grade band (K–1); talk to the location lead, not a field decision. **A parent asks about grades?** Levels + warm feedback, never scores or rankings; quizzes are teaching tools. **Child finishes everything early?** Every Build has a stretch printed in the TM — never "free play" drift.

## Closure script

"Explorers, hands on your head when your work is saved… Our goal for next time is on the board. You dreamed it, you built it — see you next week. Dream. Code. Achieve!"
