# Explorers Assessment Manual
**Document ID:** CSA-EXP-AM-EN-v1.0 · **Program:** Explorers (K–Grade 1) · Instructor-only volume — contains answer keys.

---

## 1. Assessment philosophy at this level

K–1 assessment is observational, oral, and picture-based. Quizzes are read aloud, untimed in spirit (10-minute window), and celebrated as "helping the instructor teach." Nothing is ranked or posted. Evidence for any criterion may be spoken, drawn, built, or written (→ CSA-STD-CF §7).

## 2. Assessment calendar

| When | Instrument |
|------|-----------|
| S1.1 | Diagnostic — "First Voyage" |
| Sx.3 | Quizzes Q1, Q3, Q5, Q7 (mid-semester) |
| Sx.5 | Quizzes Q2, Q4, Q6, Q8 (end of semester) + project rubric |
| C.2 | Capstone rubric + self-assessment + certificate |

## 3. Diagnostic — "First Voyage" (S1.1, no grade)

Observation checklist during Be-the-Robot, one line per child:

- Follows a 2-step oral instruction ☐ 3-step ☐
- Gives instructions in order ☐ needs prompting ☐
- Knows left/right ☐ up/down ☐
- Pencil/crayon grip and drawing comfort (note)
- Device familiarity: none / some / confident

Use results to set initial pairings and lighter-load defaults. Re-scan at S3.1 to catch growth.

## 4. Quizzes — administration standard

5 picture items, ~10 minutes, instructor reads every item aloud twice. Children mark by circling/drawing lines. Score out of 5; record same day; never returned with a "grade," returned with a sticker and one strength named aloud.

### Q1 — Which Way? (S1.3: sequencing, direction)
1. Circle the picture that comes FIRST (getting-dressed cards). **Key:** socks-before-shoes card.
2. Draw a line along the path the arrows make (3-arrow grid). **Key:** path matches →→↑.
3. Circle the arrow that means UP. **Key:** ↑.
4. The robot must reach the star (one square right). Circle the correct block card. **Key:** move-right block.
5. Circle the broken train (blocks not snapped). **Key:** the sequence with the gap.

### Q2 — Robot Ready (S1.5: sequence + triggers)
1. Circle what the computer does with instructions: guesses / follows them in order. **Key:** in order (icon: numbered list).
2. Which picture starts the program? **Key:** green flag.
3. Tap the cat → what happens next? (cards: cat spins / nothing / dog barks — given "when tapped, spin"). **Key:** cat spins.
4. Put the 3 pictures in order 1-2-3 (robot waters plant story). **Key:** seed→water→flower ordering.
5. Circle the trigger in the block train. **Key:** the tap-start block.

### Q3 — Kind & Clever (S2.3: if-then, kindness)
1. Circle the KIND message (smiling note vs. mean note pictures). **Key:** kind note.
2. IF you tap the sun, THEN…? (given rule picture). **Key:** sun smiles card.
3. Match if→then pairs with lines (2 pairs). **Key:** tap-heart→grows; flag→cat-walks.
4. Circle who might see something we share online: only me / other people too. **Key:** other people too.
5. Circle the kind thing to build for someone. **Key:** the card/gift image.

### Q4 — Footprint Finder (S2.5: if-then, digital footprint)
1. Circle what is SAFE to share: my drawing / my home address. **Key:** my drawing.
2. Circle what stays PRIVATE: first name / full name and address. **Key:** full name and address.
3. IF the card is tapped THEN it plays… (child's rule shown). **Key:** the recording icon.
4. Order the card-making steps 1-2-3 (plan → build → deliver). **Key:** that order.
5. Circle the footprint that shows kind sharing. **Key:** hearts footprint.

### Q5 — Rule Reader (S3.3: sorting rules, if-then)
1. IF it is paper THEN it goes in the ___ bin. Circle. **Key:** blue.
2. Circle the item that does NOT belong in compost. **Key:** plastic bottle.
3. The sorter's rule card shows banana→green. Circle what happens when banana is tapped. **Key:** hops to green bin.
4. Circle the picture where the rule is broken. **Key:** bottle in compost image.
5. Match 2 items to 2 bins. **Key:** paper→blue, apple core→green.

### Q6 — Bug Fixer (S3.5: debugging)
1. What is a bug? Circle: a mistake we can fix / something scary. **Key:** mistake we can fix.
2. The cat should go RIGHT but goes LEFT. Circle the block to change. **Key:** left-arrow block.
3. Order the bug-hunter questions 1-2-3 (Want? Happened? Which block?). **Key:** that order.
4. Circle the tester doing it right (taps every item vs. taps one). **Key:** taps every item.
5. The program does nothing when the flag is pressed. Circle the missing block. **Key:** start/flag trigger.

### Q7 — Map Mover (S4.3: direction, sequencing)
1. Draw the route home→school along the arrows given. **Key:** matches →↑→.
2. Circle the FIRST move for the shown route. **Key:** per map card (right).
3. Tap the park → circle what happens (given rule). **Key:** birds sing card.
4. Circle the map that shows 3 places. **Key:** the 3-place map.
5. The character walked past the school. Circle the fix: fewer steps / more steps. **Key:** fewer steps.

### Q8 — Explorer Expert (S4.5: whole-year integration)
1. Order the blocks so the dog reaches the bone (3 cards). **Key:** matches path.
2. Circle the trigger. **Key:** tap block.
3. IF you tap the house THEN…? (rule shown). **Key:** door opens card.
4. Circle what stays private online. **Key:** address card.
5. Your friend's program has a bug. Circle what a good Explorer says. **Key:** "Let's find and fix it!"

## 5. Marking guide

| Score | Meaning | Follow-up |
|-------|---------|-----------|
| 5/5 | Secure | Offer stretch variants next Build |
| 3–4 | Developing | Re-teach moment covers it; watch in Build |
| 0–2 | Needs support | 1:1 during next Build's first 10 min; note for parent update in strengths-first framing |

Class pattern rule: if 2+ children miss the same item, re-teach the concept to everyone (assume the teaching, not the children).

## 6. Practical (project) assessment — semester rubric

Used for all four semester projects; capstone uses §7. Criteria fixed program-wide (→ CSA-STD-CF §5):

| Criterion | Emerging | Developing | Proficient | Extending |
|-----------|----------|------------|------------|-----------|
| Concept & creativity | Idea chosen with much support | Idea from the brief with own touches | Own version of the brief, clearly theirs | Original twist that surprises |
| Technical skill | Blocks placed with help | Uses the semester's blocks with prompts | Uses the semester's skills correctly and independently | Combines skills beyond the ask |
| Process & problem-solving | Stops at obstacles | Tries again with encouragement | Tests and fixes with the checklist | Hunts bugs unprompted, helps others |
| Communication & sharing | Shows work silently | Says one sentence about it | Uses the presentation frame fully | Presents with confidence and answers "I wonder" questions |

Score orally gathered evidence equally. Report to parents as levels + 2–3 warm, specific sentences.

## 7. Capstone rubric (Show-and-Tell App)

Same four criteria, with Technical skill anchored to the capstone requirement: *includes a sequence AND a trigger; if-then earns Extending consideration.* Concept & creativity anchored to: *the idea is genuinely the child's own.*

## 8. Reflection, self- and peer-assessment

- **Self:** workbook reflection faces each project day; semester reflection page (best thing / trickiest / next).
- **Peer:** oral "I like…" from S1.5; "I wonder…" added from S3.5. Instructor models first, every time.

## 9. Certificate criteria

Issue the Explorer's Certificate at C.2 when the child has: presented a capstone app containing a sequence and a trigger, AND completed at least 3 of 4 semester projects. Attendance gaps are handled with make-up build time, never certificate denial without a family conversation first.
