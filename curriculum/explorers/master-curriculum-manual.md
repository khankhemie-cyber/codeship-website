# Explorers Master Curriculum Manual
**Document ID:** CSA-EXP-MCM-EN-v1.0 · **Program:** Explorers (K–Grade 1) · **Coding space:** Visual block coding · **Journey arc:** Dream · **Accent colour:** #E5A823

---

## 1. Course overview

Explorers introduces the youngest learners (Kindergarten–Grade 1) to computational thinking through visual block coding — sequencing, triggers, and simple logic — alongside early lessons in kindness online.

**Headline outcome (public promise):** *Gives a computer clear instructions and builds a simple interactive app.*

**Structure:** 4 semesters × 5 sessions + 2 capstone sessions = 22 × 55-minute sessions. 8 quizzes (2 per semester). One project per semester plus the capstone Show-and-Tell App. Session flow every week: Warm-up (5) → Teach (10) → Build (30) → Reflect (10) (→ CSA-STD-CF §4).

**Program skills (public promise):** Sequencing · Triggers & events · Simple if-then logic · Position & direction · Debugging · Kindness online & digital footprint.

**Tool:** tablet or desktop visual block-coding environment suitable for pre-readers (recommended default: ScratchJr or equivalent — CSA-STD-CF §10). No reading fluency is assumed; all student materials are icon-and-picture first.

**Alignment posture:** designed to support Ontario's early digital literacy expectations and maps to the foundational strand of BC's ADST curriculum. *Not endorsed or approved by any ministry of education.*

## 4. Weekly progression — full session sequence

### Semester 1 — My Helpful Robot
*Big Idea: Computers follow clear, ordered instructions.*

| Code | Title | Objectives (students will…) | New vocabulary |
|------|-------|-----------------------------|----------------|
| S1.1 | Be the Robot | give and follow step-by-step instructions with their bodies; explain that a computer only does what it is told, in order | instruction, robot, order |
| S1.2 | First Blocks | connect blocks to make a character move; predict what a short block sequence will do | block, program, sequence |
| S1.3 | Which Way? **(Q1)** | move a character up/down/left/right to reach a goal; describe a path using direction words | direction, up/down/left/right |
| S1.4 | Make It Start | use a start trigger and a tap trigger to begin actions; explain "when this happens, that starts" | trigger, event, tap |
| S1.5 | My Helpful Robot **(Q2)** | combine sequence + triggers so their robot character performs a helpful job; present it to a partner | (review week) |

**Project milestone:** working Helpful Robot scene presented S1.5. **Success criteria:** robot moves in a planned order; at least one trigger; child can say what each block does.

### Semester 2 — Kindness Cards
*Big Idea: What we build and share online can make someone's day better.*

| Code | Title | Objectives | New vocabulary |
|------|-------|------------|----------------|
| S2.1 | Kind Words, Big Plans | identify kind vs. unkind messages; plan a card for a real person using the picture planner | kind, message, plan |
| S2.2 | When You Tap… | build a card where tapping makes something happen (if tapped → then show/animate) | if, then |
| S2.3 | Sounds & Surprises **(Q3)** | record a kind voice message into their card; explain that shared things can be seen by others | record, share, online |
| S2.4 | My Digital Footprint | tell what is safe to share (first name, drawings) vs. keep private (full name, address); finish building cards | private, footprint |
| S2.5 | Card Delivery Day **(Q4)** | present their card and deliver it; give a partner one "I like…" | (review week) |

**Project milestone:** interactive Kindness Card delivered S2.5. **Success criteria:** at least one if-then interaction; a kind message (words, drawing, or recording); child can name one thing that stays private.

### Semester 3 — Recycling Sorter
*Big Idea: Programs can help us make good decisions.*

| Code | Title | Objectives | New vocabulary |
|------|-------|------------|----------------|
| S3.1 | Sort It Out | sort real objects by rule; state a sorting rule as "if… then…" | sort, rule, recycle |
| S3.2 | Teaching the Sorter | build characters that respond differently when tapped (if this item → then this bin) | choose, respond |
| S3.3 | Bug Hunt **(Q5)** | find and fix a planted mistake in a program; explain that a bug is a mistake we can fix | bug, debug, fix |
| S3.4 | Test and Fix | test their sorter, find their own bugs, and fix them; add a third category | test |
| S3.5 | Sorter Demo Day **(Q6)** | demonstrate the sorter; explain one bug they fixed | (review week) |

**Project milestone:** Recycling Sorter demo S3.5. **Success criteria:** two or more if-then choices; child found and fixed at least one bug; child can say the sorting rule aloud.

### Semester 4 — My Neighbourhood Map
*Big Idea: Code can represent the real world around us.*

| Code | Title | Objectives | New vocabulary |
|------|-------|------------|----------------|
| S4.1 | Places I Know | draw a map of 3 real places; plan which places their scene will show | map, place, real |
| S4.2 | Walking the Map | program a character to travel a route between places using direction blocks in order | route |
| S4.3 | Tap the Places **(Q7)** | add triggers so tapping a place makes something happen (sound, speech, animation) | (combining) |
| S4.4 | Fix the Journey | debug routes that go wrong; add a second character or detail | (debugging) |
| S4.5 | Map Tour Day **(Q8)** | give a "tour" of their neighbourhood map to the class | (review week) |

**Project milestone:** interactive Neighbourhood Map toured S4.5. **Success criteria:** a route built from an ordered sequence; at least two tap triggers; one bug found and fixed during building.

### Capstone — Show-and-Tell App

| Code | Title | Objectives |
|------|-------|------------|
| C.1 | My Own Idea | choose their own app idea with the picture planner; build the main scene using any skills from the year |
| C.2 | Showcase | finish, rehearse with the presentation frame ("My app is… When you tap… I'm proud of…"), and present at the family showcase |

**Success criteria:** the idea is the child's own; app uses a sequence AND a trigger (if-then encouraged); child presents 3 sentences about it.

## 5. Timing, materials, and classroom preparation

- **Timing:** every session 55 minutes on the standard four-phase flow; quiz sessions (x.3, x.5) open with the 10-minute picture quiz (→ CSA-EXP-AM-EN).
- **Materials (whole program):** class tablet/device set with the block-coding app; instructor demo device + display; printed visual schedule; sequencing cards, direction arrows, sorting objects (S3), paper maps (S4); Printable Resource Book masters for the semester (→ CSA-EXP-PRB-EN); workbooks and crayons/pencils every week.
- **Preparation:** room per CSA-STD-OPS §2; app opened to a fresh project on every device; that session's printable copied one per student; unplugged-fallback activity from the PRB packed in case of tech failure.

## 6. Teacher notes (program level)

> **📌 Teacher Note:** Explorers are pre-readers. Never gate progress on reading. Model on the big screen, use icon cards, and let children echo instructions aloud.

> **⚠️ Watch For:** K–1 fine-motor variance is huge. Drag-and-drop struggles are motor, not conceptual — offer stylus, partner-drag, or "you point, I drag" without comment.

> **🤝 Every Learner:** every Build has a lighter-load variant (fewer blocks, pre-made characters) and a stretch (add a sound, add a second character). Movement is legitimate: "be the robot" breaks any time attention frays.
