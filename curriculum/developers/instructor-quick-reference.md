## Timing guide

Warm-up 5 → Teach 10 → Build 30 → Reflect 10. Quiz days: Quiz 10 → Re-teach 5 → Build 30 → Reflect 10. Trace before type; protect the Build.

## Setup checklist (every class)

☐ Room/tech per OPS §2 · ☐ playground + starter open, **console visible** · ☐ trace tables + Error Detective cards on desks · ☐ printable copied · ☐ schedule/agreements posted · ☐ fallback (PRB-16) · ☐ quizzes counted (quiz days) · ☐ roster + accommodations read · ☐ S3.4: reference materials staged · ☐ C.2 −2 weeks: family invites out.

## Materials checklist (program cupboard)

Keyboard devices + spares · demo + display · dry-erase trace-table sets + markers · card decks (missions, branches, headlines, scenarios, snack facts) · card-stock checklists · planners/user-test sheets · certificates.

## Software checklist

Browser JS playground with console + live preview · class accounts only · starters staged per session (`timer`, `snack`, `quiz`, `budget` series) · student work saved to class space every session.

## Assessment schedule

Diagnostic S1.1 · quizzes x.3/x.5 (Q1–Q8, keys AM §4) · project rubric every x.5 · capstone rubric + user-test evidence + certificates C.2 · record within 24 h · rubric + 2–3 warm sentences home after every x.5.

Timer ★ S1.5 · Calculator ★ S2.5 · Fact-or-Fake ★ S3.5 (verification enforced S3.4) · Budget Buddy ★ S4.5 · Capstone C.1–C.2.

## Missed-session compression

One session lost: fold x.1 into x.2's warm-up; quiz days stay; never cut x.5. Two+: curriculum lead (FDS §3).

## Troubleshooting (top 6)

| Symptom | Fix |
|---------|-----|
| "not defined" error | Name/case mismatch or never defined — Detective 1 & 5 |
| Click does nothing | Trace the chain; check the wire-up name |
| Branch never fires | `=` vs `===`; read the condition as a question |
| Loop wrong | Trace table, 3+ rows |
| `[3]` on a 3-item array | Index starts at 0 — human-array replay |
| Error-message panic | "The console is a clue, not a verdict" |

## FAQs

**Child has no coding background?** Program assumes none; Builders knowledge helps but S1.1 starts from zero. **Media topics safe?** Age-safe, non-political by design (animals/space/food/records). **Family finances in S4?** Never — card scenarios only. **Kid wants games not tools?** Capstone spec digs for the friction behind the wish; games with a purpose can qualify if they hit the technical bar. **Already knows JS?** Stretch lists every session; placement → location lead.

## Closure script
