# Developers Printable Resource Book
**Document ID:** CSA-DEV-PRB-EN-v1.0 · **Program:** Developers (Grades 4–5) · Single-sided photocopy masters, black-and-white safe (→ CSA-STD-PUB §11).

---

## PRB-1 — Console Mission Cards (S1.1–S1.2)
Cut-apart mission decks for console play: "make a variable for your age → change it → combine two variables", graded easy→spicy. Keeps early Build phases self-serve.

## PRB-2 — Variable Box Sheets (S1.1)
Labelled-box drawing frames: box name plate + value window + "history" line for updates. Matches the workbook's box model exactly.

## PRB-3 — The Chain Poster (S1.4)
Wall poster: CLICK → FUNCTION RUNS → VARIABLE CHANGES → DISPLAY UPDATES, with a blank-version handout for students to fill with their own timer's names.

## PRB-4 — Trace Tables (all semesters)
Laminated card-stock grids: variable-trace (name/value per step), loop-trace (`i` / element / total per turn), branch-trace (condition / true-false / which branch). The program's core thinking tool — one set per student, dry-erase.

## PRB-5 — Error Detective Checklist (all semesters)
Card stock: 1 read the console clue aloud ☐ · 2 names match exactly? (case!) ☐ · 3 brackets & parens paired? ☐ · 4 `=` put vs `===` ask? ☐ · 5 was it ever defined? ☐. Magnifying-glass motif.

## PRB-6 — Home Link Notes (Sx.5)
Half-page per semester (What we built · Ask your Developer · Try at home): S1 "spot the variables" in a board game; S2 read one nutrition label together; S3 the dinner fact-check game (one true, one fake, family verifies); S4 estimate-then-check a grocery total.

## PRB-7 — Branch & Operator Cards (S2.1–S2.2)
Front: fork-in-the-road frames (condition signpost, two path boxes). Back: operator reference `>` `<` `===` with true/false examples and the `=` vs `===` trap warning.

## PRB-8 — Snack Fact Cards (S2.4)
Deck of realistic nutrition-style cards (per-serving sugar, fibre, etc.) for calculator testing — invented brands, plausible numbers, no real products.

## PRB-9 — Headline Deck & Verification Sheet (S3.1, S3.4)
Front: 20 age-safe headline cards (mixed true/false: animals, space, food, records) + the 3-checker-question sort mat. Back: verification sheet — fact → source note line; fake → why-it's-fake line.

## PRB-10 — Money Scenario Cards (S4.1, S4.4)
Eight kid-real budget scenarios (class-trip snacks $20, pet fund, gift for grandma, bake-sale stock) with income, expense menus, and a built-in "choice moment". Needs/wants sort cards included.

## PRB-11 — Problem-Solver Planner (C.1)
Spec spread: the problem / who has it / what the app does / tools needed checklist (mirrors the capstone bar) / screen sketch frame. Problem-hunt spark cards on a second page ("what do you always forget? what fight repeats at home?").

## PRB-12 — User-Test Sheet (C.2)
Protocol card: builder watches silently ☐ · tester tries it cold · tester answers: What was it for? What confused you? · builder writes ONE fix. Two tests per page.

## PRB-13 — Presentation Frame Cards (all x.5, C.2)
Palm cards: per-semester demo frames + capstone pitch frame (problem → solution → demo → what I'd add next).

## PRB-14 — Visual Schedule & Agreements Posters — shared design, Developers-blue accent edition.

## PRB-15 — Circuit Tracker Poster — wall version of the workbook circuit path, class edition, first names only.

## PRB-16 — Unplugged Fallback Pack
S1: human variables (kids hold value cards, "run" update lines) · S2: rating-ladder floor game (walk to your rung) · S3: paper array-and-loop relay with index cards · S4: envelope budget game with paper alerts.

## PRB-17 — Certificate Master — Developer's Certificate line-art + navy/gold version (criteria → AM §9).
