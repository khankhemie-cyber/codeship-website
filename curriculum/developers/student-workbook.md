# Developers Student Workbook
**Document ID:** CSA-DEV-SW-EN-v1.0 · **Program:** Developers (Grades 4–5) · Print spec: 11 pt body, monospace code boxes, trace-table grids throughout. Perfect-bound, perforated certificate.

*Designer note: this workbook is a developer's logbook — trace tables, specs, bug logs, and personal code snippets. Handwriting code before typing it is a deliberate learning step.*

## Semester 1 — Homework Timer & Focus Tool ⏱️
**Opener:** *Variables and functions let programs track and respond to change.*

| Page | Session | Activities |
|------|---------|------------|
| S1.1 | Hello, JavaScript | Draw your variable boxes (label + value). Trace table: `let x = 10; x = x + 5; x = x - 3`. My first console line, handwritten. |
| S1.2 | Numbers That Move | The strangest line: explain `count = count - 1` in your own words. Countdown trace table (5 rows). |
| S1.3 | Name the Job | Function machine drawing: name plate, job inside, call button. Write your two function names + what job each does. "I can" check: *I can explain what a variable holds.* |
| S1.4 | When You Click | The chain, drawn: CLICK → function → variable → display (fill in yours). My focus message draft. |
| S1.5 | Timer launch ★ | Demo card: "My tool helps me ___ / Watch the chain: …" Bug log #1: one error I got + what the console told me + the fix. Reflection meter. |

## Semester 2 — Healthy Snack Calculator 🥕
**Opener:** *Conditionals let programs make decisions based on data.*

| Page | Session | Activities |
|------|---------|------------|
| S2.1 | If This, Then That | Fork-in-the-road diagram: condition on the signpost, two paths with my messages. Predict-the-branch practice (3 traces). |
| S2.2 | Compare & Decide | Operator table to complete (`>`, `<`, `===` with true/false examples). My rating ladder: 3 rungs with my thresholds + messages. |
| S2.3 | Functions With Inputs | Function machine v2: input slot! Label `rate(sugar)` parts: parameter, body, return. Feed the machine: 3 inputs → outputs. |
| S2.4 | Building the Calculator | Assembly map to complete: input → variable → rate() → message. Nutrition-label reading practice: find sugar per serving on 2 printed labels. |
| S2.5 | Demo day ★ | Narrate-the-branch script: "When I enter ___, the ___ rung fires because ___." Bug log #2. Semester reflection. |

## Semester 3 — Fact or Fake? Quiz 📰
**Opener:** *Arrays and loops help programs process lots of information — just like people should question lots of sources.*

| Page | Session | Activities |
|------|---------|------------|
| S3.1 | Question Everything | The 3 checker questions, my copy: Who made it? What's the evidence? What do others say? Headline verdicts table (headline / my verdict / which question decided it). My 3 fact-fake pair ideas. |
| S3.2 | Lists in Code | Array diagram: compartments numbered **from 0** (trap warning drawn by me). Write my `questions` array. Index practice: what's at `[2]`? |
| S3.3 | Loop the Loop | Loop trace table: `i` / `questions[i]` for every turn. "Loops do the boring part, I do the thinking part" — my example. |
| S3.4 | Building the Quiz | **Verification sheet:** each fact → source note; each fake → why it's fake. Score-variable plan. |
| S3.5 | Quiz arcade ★ | Arcade scorecard: quizzes I played / nearly-fooled-me tally. Circle share: the fake that nearly got me + the question that catches it. Reflection. |

## Semester 4 — Budget Buddy 💰
**Opener:** *Code can help people make smarter decisions with their money.*

| Page | Session | Activities |
|------|---------|------------|
| S4.1 | Money In, Money Out | Needs/wants sort (my honest version). My scenario plan: income, expenses, the choice moment. |
| S4.2 | The Running Total | Accumulator trace table (start 0, one row per expense). Paper-math check box: code total = my total? ☐ |
| S4.3 | Budget Alerts | My alerts, drafted in my voice + their thresholds. Compound condition practice: when do BOTH have to be true? |
| S4.4 | Building Budget Buddy | Assembly map; savings-goal math: goal − total = ___ to go. Bug log #3. |
| S4.5 | Buddy demo ★ | Demo script: scenario, loop narration, alert moment, "the smarter decision my Buddy enables". Semester reflection. |
