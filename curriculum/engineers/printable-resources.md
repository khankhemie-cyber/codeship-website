# Engineers Printable Resource Book
**Document ID:** CSA-ENG-PRB-EN-v1.0 · **Program:** Engineers (Grades 6–8) · Single-sided photocopy masters, black-and-white safe (→ CSA-STD-PUB §11).

---

## PRB-1 — Security Story Cards & Worst-Passwords Gallery (S1.1–S1.2)
Front: six age-appropriate "how the account actually fell" story cards (guessed common password; reused password after a leak; phishing message; shoulder-surfed PIN…) each ending in the defence that would have stopped it. Back: the famous published worst-passwords list for the guessing game. Defence-framing note to instructor printed in the margin.

## PRB-2 — Password Rule Cards (S1.3)
Deck of rule cards: LENGTH ≥ 12 · HAS A DIGIT · MIXED CASE · NO BANNED WORDS · SPECIAL CHARACTER (stretch) — each with the code pattern on front and the "why it works" on back.

## PRB-3 — Personal Safety Audit (S1.5)
Fold-and-seal private checklist (concepts only, taken home unread): reuse habits ☐ · phishing red flags I know ☐ · recovery info set ☐ · who I'd tell if something felt wrong ☐. Family conversation prompts on the flap.

## PRB-4 — Python Syntax Reference Card (all semesters)
Card-stock desk reference: variables, `print`/`input`, f-strings, conditionals with `and`/`or`, `def`/`return`, `for`/`while`, list & dictionary basics, reading a traceback (line number → look up one line too).

## PRB-5 — Traceback Detective Checklist (all semesters)
1 read the error name + line number aloud ☐ · 2 check that line AND the line above ☐ · 3 `:` and indentation present? ☐ · 4 names match exactly (case)? ☐ · 5 defined before used? ☐.

## PRB-6 — Home Link Notes (Sx.5)
Half-page per semester (What we built · Ask your Engineer · Try at home): S1 password-habits conversation (concepts, no actual passwords); S2 spot-the-AI-in-our-house hunt; S3 family bot test with the 5-question sheet; S4 estimate-then-check data game (guess the mean, then compute).

## PRB-7 — AI-in-Your-Day Cards (S2.1)
Sorting deck: autocorrect, face unlock, spam filter, video recommendations, thermostat schedule, chess app — sorted RULES vs. LEARNED with justification lines.

## PRB-8 — Evaluation Sheet & Findings Brief Frame (S2.3, S2.5)
Front: held-back test table (10 rows: input / expected / predicted / right?) + accuracy = right/total = ___%. Back: findings brief frame — trained / tested (accuracy) / what broke / the fix (before→after) / what we'd never trust it to do.

## PRB-9 — Bias Skew Kits (S2.4)
Instructions + example manifests for controlled skew experiments per sorter theme (e.g., "make every 'cat' example orange"; "photograph all 'paper' items on the same desk") with rebalance manifests for the fix stage.

## PRB-10 — Bot Transcript Cards (S3.1)
Six short chat transcripts to autopsy: canned-rule replies vs. learned-sounding replies vs. honest fallbacks vs. over-promising bots. Discussion prompts on back.

## PRB-11 — Responsible AI Checklist (S3.4; capstone edition C.2)
The five-question audit: WHO does it help? · WHO could it harm? · WHAT data does it touch — and does it need to? · Does it FAIL SAFELY? · Is it HONEST that it's a bot/program? Findings + fix log at the bottom. Capstone edition adds the security column (test data only, no personal data, demo fallback ready) and a sign-off line.

## PRB-12 — User-Test Sheets (S3.5)
Protocol: tester asks 5 real questions cold · builder logs hit/fallback silently · tester answers: did it help? where did it lose you? · builder commits ONE improvement.

## PRB-13 — Dataset Pack Case Files (S4.1, S4.5)
One case-file cover per dataset pack (weather history / sports stats / nutrition tables / endangered-species counts): column dictionary, units, row count, provenance note, and the 3-question frame ("answerable from these columns?" check). Back: insight report frame — question → evidence → insight → caveat.

## PRB-14 — Misleading-Graph Gallery (S4.4)
Six deliberately misleading charts (truncated axis, cherry-picked range, missing labels, 3-D distortion) with "find the trick" prompts + the honest-chart rules strip.

## PRB-15 — SDG Cards (C.1)
Seventeen UN Sustainable Development Goal cards, kid-clear phrasing, each with 2 "prototype-sized" example angles to demonstrate scope (SDG 6: "one home's water waste", not "fix the ocean").

## PRB-16 — Innovation Planner & Pitch Frame (C.1–C.2)
Front: problem / who has it / my solution / skill families (≥2 check) / demo plan / instructor scope sign-off. Back: 5-part pitch frame with timing boxes (problem → solution → demo → impact → next steps).

## PRB-17 — Certificate Master
Engineer's Certificate line-art + navy/gold version (criteria → AM §9).

## PRB-18 — Unplugged Fallback Pack
S1: paper password-rules tournament (rank test-strings by hand) · S2: human-classifier game (class learns from labelled doodles, then meets skewed doodles) · S3: paper bot — intent cards and a human "interpreter" · S4: dice-and-tally dataset built live, analyzed by hand.
