## Timing guide

Warm-up 5 → Teach 10 → Build 30 → Reflect 10. Quiz days: Quiz 10 → Re-teach 5 → Build 30 → Reflect 10. Protect the Build; scope talks stay in Teach.

## Safety rails (recite until reflex)

No real passwords, ever · no personal data in models/bots/datasets · defence, never attack technique · honest results only (accuracies as measured, caveats stated).

## Setup checklist (every class)

☐ Room/tech per OPS §2 · ☐ Python env + starter staged · ☐ unit assets staged (S2: trainer + example sets/skew kits; S4: dataset packs) · ☐ reference + detective cards on desks · ☐ printable copied · ☐ schedule/agreements posted · ☐ fallback (PRB-18) · ☐ quizzes counted (quiz days) · ☐ roster + accommodations read · ☐ C.1: planner sign-offs planned · ☐ C.2 −2 weeks: invites out; panel confirmed if arranged.

## Materials checklist (program cupboard)

Keyboard devices + spares · demo + display · card decks (story, rule, AI-day, transcript, SDG) · skew kits · dataset pack case files · card-stock checklists (PRB-4, 5, 11) · planners/sheets · certificates.

## Software checklist

Browser Python environment · no-code ML trainer · CSV/chart helper starters (`checker`, `bot`, `data` series) · class accounts only · student work saved to class space every session.

## Assessment schedule

Diagnostic S1.1 · quizzes x.3/x.5 (Q1–Q8, keys AM §4) · project rubric every x.5 · capstone rubric + ethics/security check + certificates C.2 · record within 24 h · rubric + 2–3 warm sentences home after every x.5.

## Project schedule

Checker ★ S1.5 · Sorting AI ★ S2.5 (bias experiment S2.4 is mandatory, never skipped) · Chatbot ★ S3.5 (responsibility review S3.4 mandatory) · Data Detective ★ S4.5 · Innovation Challenge C.1–C.2 (scope sign-off C.1; demo rehearsed twice before C.2).

## Missed-session compression

One session lost: fold x.1 into x.2's warm-up; quiz days stay; never cut x.5, S2.4, or S3.4. Two+: curriculum lead (FDS §3).

## Troubleshooting (top 6)

| Symptom | Fix |
|---------|-----|
| SyntaxError wall | Traceback line + line above; `:` and quotes |
| IndentationError | "Indentation is grammar" — re-indent block |
| NameError | Case/typo; defined before used? |
| Model "wrong" | Few/samey examples → add variety, retrain, re-test |
| Bot never matches | `.lower()` everything; keyword actually present? |
| Absurd stats | Sanity-check: right column? numbers not strings? units? |

## FAQs

**A student asks how to hack something?** Redirect to defence ("how would you protect it?") — every time, no exceptions. **Parent worried about "AI class"?** Point to PH §5: ethics inside the curriculum, no personal data, honest evaluation culture. **Real passwords in the checker?** Never — test strings only; reset the norm immediately if breached. **Ethics debates get heated?** Grade reasoning, honour viewpoints, land on the taught framework. **Student far ahead?** Stretch lists every session + deeper capstone scope; placement → location lead. **French delivery?** Engineers is published in French — see CSA-STD-FR and your location lead.

## Closure script

"Engineers, commit your work — save and close. One line for the log: what did you prove today? Goal's on the board. Dream. Code. Achieve."
